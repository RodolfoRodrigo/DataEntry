📌 DataEntry

DataEntry is a lightweight browser extension (Chrome/Edge) built with JavaScript, HTML, and CSS, designed to provide a simple and practical interface for data entry directly within the browser.

The project includes a popup-based UI that allows users to interact quickly with the extension, making it suitable for scenarios where fast and efficient data input is required without leaving the current webpage.

🚀 Technologies Used

JavaScript – core logic and behavior

HTML / CSS – user interface and styling

Browser Extension Manifest – extension configuration and permissions

🧠 Project Purpose

The main goal of this project is to demonstrate how to build a simple and extensible browser extension focused on data entry. It serves as a solid foundation for future enhancements, such as integrations with external APIs, form automation, or productivity tools, while keeping the structure clean and easy to maintain.
