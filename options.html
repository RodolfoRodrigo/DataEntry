🔑 API Key do OpenAI
Para usar o assistente de IA, você precisa de uma API Key do OpenAI. A extensão usa GPT-4o para processar suas transcrições e criar registros no Salesforce de forma inteligente.
Escolha o idioma preferencial para as transcrições de áudio. Quando "Detectar automaticamente" estiver selecionado, o modelo tentará identificar o idioma usado na gravação.
Defina se o assistente deve redirecionar esta aba para o novo registro ou abrir o resultado em uma nova aba após a criação.

📌 Como obter sua API Key:

1. Acesse platform.openai.com/api-keys
2. Faça login ou crie uma conta
3. Clique em "Create new secret key"
4. Copie a chave e cole aqui

💾 Cache de Metadados
A extensão armazena metadados dos objetos Salesforce localmente para melhorar a performance e reduzir chamadas à API.
